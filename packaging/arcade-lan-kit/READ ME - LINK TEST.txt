TOKYO WARS + RAVE RACER + TIME CRISIS 2 - LINK PLAY TEST KIT (games' 0.9.2)
============================================================================

This folder is a TEST version of Tokyo Wars, Rave Racer and Time Crisis 2
that can link cabinets over a network, the way the original arcade boards
linked over their cable. Everything they need is in this folder (the game
files are in "roms" and "Time Crisis 2\extracted"). They do not use the
internet.

NEW IN THIS KIT (0.9.2, 25 Oct): the author's 0.9.1/0.9.2 changes are in. For these
games: Display > Aspect ratio now offers 16:9 while Widescreen is on; Rave Racer saves
every session you play as rr_last.rec (the one before as rr_prev.rec; a linked copy as
rr_cab1_last.rec ...) so a problem can be replayed exactly. The link itself is unchanged and
passed the same tests. The previous kit, link-test-0.9.0, is kept as it was. These programs
are new files, so on the cabinet PCs Windows Firewall asks once again: allow Private.
To stop the session recordings: START HERE > Tools > 4 (all games), or record=off in link.cfg (and in Time Crisis 2\tc2_link.cfg).

EASIEST WAY IN: double-click "0 - START HERE - choose a game.bat". Pick the
game, then how to play it, with one key each; it starts the matching
launcher below. Its Tools page switches the link lights (network activity
on screen) on or off for all games. All the numbered launchers still work on their own too.


NEW: TIME CRISIS 2 TWIN CABINET
-------------------------------
The two PCs of a Time Crisis 2 twin cabinet now link the way the two
original boards did: LINK PLAY appears on the game-mode screen ("BLUE PLAYER
IS YOUR TEAMMATE" on the left, "RED PLAYER IS YOUR TEAMMATE" on the right)
and both players play the same mission together, each on their own screen.
(The original author's Time Crisis 2 has no link; this is ours.)

   T1  try both cabinets on THIS PC (two windows side by side)
   T2  the LEFT cabinet's PC  (red player)  - full screen (recommended)
   T3  the RIGHT cabinet's PC (blue player) - full screen (recommended)
   T4 / T5  the same in a window
   T6  BOTH screens from ONE PC: two monitors, two light guns (below)

T6 - ONE PC FOR THE WHOLE TWIN CABINET:
   - The left (red) player's game goes full screen on the left monitor and
     the right (blue) player's on the right monitor, linked to each other on
     this PC. Monitors are counted from the left as Windows arranges them
     (Settings > Display), so put them in the same order as the screens.
   - Each screen reads ONLY its own gun (Gun4IR, Sinden, AimTrak etc. are
     mice to Windows; a plain mouse works too). The FIRST gun to shoot
     becomes the red player's, the NEXT one the blue player's. They are
     saved in "Time Crisis 2\guns.cfg" and stay on their sides from then on.
     To choose again, delete guns.cfg and restart.
   - Gun buttons: trigger = shoot, right or middle button = pedal (wire the
     pedals into the guns' buttons). Point off the screen = reload.
   - A light gun aims across the whole of its own screen (calibrate each gun
     to its screen). A mouse moves only its own screen's crosshair; the red
     crosshair is the left player's, the blue one the right player's.
   - With only one monitor, the two games open as two windows side by side.

How it behaves, like the real pair:
   - Switch BOTH cabinets on together. Each shows "WAITING FOR THE ...
     CABINET" for up to 60 seconds until the other one is there; then both
     start together. S on that screen = play alone now.
   - A cabinet switched on later, or restarted, plays alone until BOTH are
     restarted (the game itself only links two boards that start together).
   - If one cabinet is switched off in the middle of a game, the other keeps
     playing: the game's computer partner takes over.
   - The two games are kept in step with each other. If one PC stutters
     for a moment, the other waits for it (a short pause on both screens)
     instead of losing its partner. Closing one game tells the other at
     once; a PC that stops answering for 5 seconds counts as switched off.
   - Both PCs need the SAME copy of this kit. An older Time Crisis 2 kit
     will not link with this one, and the wait screen says so.
   - The PCs find each other on the network by themselves. To give the
     address instead, or change the wait, edit "Time Crisis 2\tc2_link.cfg".
   - The first time, Windows asks whether TimeCrisis2-Link may use the
     network: tick "Private networks" and Allow (on both PCs).
Keys: 5 = coin (4 coins a credit), mouse = aim, left button = shoot,
right button or Z = pedal, F2 = test menu, Esc = menu. A light gun works too.
Checked here: linked attract, LINK PLAY, a linked mission in step at arcade
speed, with 3% of the network messages lost, with the two PCs' clocks 0.2%
apart, one switched off mid-game, one switched on late, one PC stalling for
1.5 seconds, and both windows on one PC played by hand. Not yet checked:
two real PCs on your switch, and a whole game played to the end.

The first time, Windows will ask again whether the games in THIS folder

A. TRY IT ON ONE PC
-------------------
Double-click one of:
   "1 - Tokyo Wars - try 2 cabinets on this PC"
   "2 - Tokyo Wars - try 4 cabinets on this PC"
   "4 - Rave Racer - try 2 cabinets on this PC"
   "5 - Rave Racer - try 4 cabinets on this PC"
Several game windows open, one per cabinet, side by side (on a small
screen they overlap a little). Only cabinet 1 has sound.
Do NOT drag a window while the cabinets are linked: Windows holds that
game still while its window moves, and a cabinet that stops for more than
a tenth of a second is dropped from the link until everything restarts.

These launchers give each window its cabinet number every time they start,
so on their Network page the settings are shown but cannot be changed.
The Network page is for a cabinet PC (section B).

Click a window to control that cabinet with the keyboard.

Tokyo Wars:  5 = coin   Enter = start   arrows = steer / pedals   Z / X = triggers
   Put a coin in and press Start on two windows within a few seconds of each
   other: both players join the same battle.

Rave Racer:  5 = coin   X (or Up) = gas   Z (or Down) = brake   arrows = steer
             A / S = gear down / up   V = view
   Put a coin in on both windows and choose LINK (linked play) on each: both
   cars race in the same race.

Note: two copies on ONE PC share its graphics chip, and on a laptop that can
make a game stutter for a moment when new scenery appears. A stutter longer
than about a tenth of a second looks like a link break to the other cabinet.
With one PC per cabinet (the real setup) this does not happen.

AUTOMATIC CHECK (Rave Racer, 4 cabinets)
   "7 - Rave Racer - automatic 4-cabinet check"
Four hidden copies of Rave Racer (no windows, so no stutter) link up, put a
coin in, choose linked play and race each other by themselves for 100
seconds. Then it shows PASS or FAIL for each cabinet: did it link with all
four at start-up, and did the game keep its link for the whole race. Do not
start the game yourself while it runs (they would use the same network
ports). It does not touch your test-menu settings.


PARTY MODE: SEVERAL PLAYERS ON ONE PC (just for fun)
----------------------------------------------------
The "P" launchers turn one PC into a split screen, a player in each part:
   P1 - P4   Tokyo Wars, 2 or 4 players
   P5 - P8   Rave Racer, 2 or 4 players
each either "keyboard + controllers" (player 1 on the keyboard) or
"controllers" (everyone on a game controller).

- Plug the controllers in BEFORE starting. Player N gets the Nth
  controller (in the "keyboard +" launchers player 2 gets the first one,
  and so on). Each picture says whose it is for a few seconds.
- Standard game controllers only (Xbox, PlayStation, Switch Pro, 8BitDo
  ...). On a controller: Back / Select = coin.
     Tokyo Wars: Start = start, left stick = drive, the buttons fire.
     Rave Racer: right trigger = gas, left trigger = brake, left stick
                 = steer; choose LINK on each picture to race together.
- The keyboard goes to whichever picture was clicked last: the keyboard
  player clicks their own picture once.
- Only player 1 has sound.
- Each picture is the arcade's 4:3 shape, so there are black bars at
  its sides. The Esc > Display page has widescreen settings if you
  would rather fill it (they are remembered for all the pictures).
- The pictures cover the whole screen, the Windows task bar included.
  (To keep the task bar in view, open the launcher in Notepad and change
  --party to --party-taskbar on every line.)
- Close each picture with Alt+F4 (or Esc > File > Exit).

The four games share the PC's graphics chip, so they keep in step with
each other: when one has a slow moment they all wait for it, and the
pictures hold for an instant, instead of that player being dropped from
the game. It still needs a reasonably strong PC to be smooth with four.
This is only for copies on ONE PC - real cabinets never wait for each
other.


B. SEVERAL PCs ON THE SAME NETWORK (e.g. a cabinet PC in each machine)
----------------------------------------------------------------------
1. Copy this whole folder to every PC.
2. On each PC start the game ("3a - Tokyo Wars - cabinet on the network -
   FULL SCREEN" or "6a - Rave Racer - ..."), press Esc and open the Network
   page.
   "This PC:" near the bottom is that PC's address - note it down.
3. THE EASY WAY: start the game on EVERY PC, then on each PC open the
   Network page and choose "Find cabinets" (Enter). After a moment it lists
   the PCs running the game, with their names, e.g.
      Found 3: 192.168.1.11 CABINET-1 (this PC), 192.168.1.12 CABINET-2, ...
   Choose "Use the 3 found" (Enter): the list is filled in (sorted, so it
   comes out the same on every PC), with This cabinet on Auto. Do this on
   each PC (or copy that link.cfg to the others), then go to step 5.
   BY HAND instead - on ONE PC, on the Network page:
      Link play         On
      This cabinet      Auto
      Cabinets in set   how many PCs (e.g. 3)
      Cabinet 1         the address of the PC that is cabinet 1
      Cabinet 2         the address of the PC that is cabinet 2   ...
   (an address: Enter, type it, Enter)
   The settings are saved at once, in link.cfg in the game's folder.
4. Copy that link.cfg to the same folder on every other PC. With "This
   cabinet" on Auto each PC finds its own number: its place in the list.
   (A PC whose address is not in the list says so and does not link.)
   You can also set "This cabinet" to a number by hand instead.
5. Close the game on every PC and start them all again with the FULL
   SCREEN launcher (3a or 6a): the cabinets look for each other when they
   start, like the real boards. While they look, the screen shows each
   cabinet (found / waiting), how quick the network is to each one, and
   the countdown. To play on this PC without the link instead (say one
   of the other PCs is broken), press S while it looks: this PC starts at
   once on its own, and the others carry on without it. That is only until
   the game is closed - the next start looks for the cabinets as usual.
6. The first time, Windows may ask whether the game may use the network:
   tick "Private networks" and click Allow. If it did not ask and the
   cabinets do not see each other, that permission is the first thing to
   check.

FULL SCREEN, NOT A WINDOW (important with 3 or more PCs)
   The linked games expect every cabinet to answer within about a tenth of
   a second, all the time, as the real boards did on their cable. In a
   window, a PC with modest graphics (e.g. Intel UHD 630) can freeze for a
   moment in busy scenes; with 3 or more cabinets that is enough for the
   games to lose the link, and battles end early ("BATTLE OVER").
   In full screen this does not happen. So:
   - use the FULL SCREEN launchers (3a, 6a); the window ones (3b, 6b) are
     for setting up and for 2-PC tests;
   - start the games full screen - switching to full screen while linked
     freezes the game for a second or so, which can drop the link once;
   - for the fastest mode, set Esc > Display > Window mode to
     "Fullscreen (exclusive)" once on each PC (it is remembered).
   Esc opens the menu over the game; File > Exit (or Alt+F4) closes it.

Wi-Fi works for testing, but Wi-Fi can pause for a moment to save power,
which can drop the link too. If the link drops on Wi-Fi, set the PCs'
power plan to "Best performance" (and plug laptops in). At the arcade the
PCs should be on a cable to the switch, and each PC should keep the same
address (set a fixed address in Windows, or reserve it in the router).


HOW LINKING WORKS (the same rule as the real boards)
----------------------------------------------------
While linked, the game does not pause: opening the Esc menu (or pressing
P) leaves it running behind the menu, because a cabinet that stops is
dropped by the others. Settings changed on a running cabinet are used
when the cabinets are next started.

The cabinets look for each other when they are started, and only then.
Each window first shows "waiting for cabinet ..." in its title bar; when
every cabinet is there they all start the game together. If a cabinet has
not appeared after 60 seconds (the Network page's "Wait at start-up"), the
others start without it.

A cabinet started AFTER the others are already playing (started late, or
restarted after a crash) is NOT let in: its title says "NOT LINKED" and it
plays on its own. To get every cabinet linked again, close all of them and
start them all again - like switching the whole cabinet off and on.
If one cabinet crashes while the others are playing, the others carry on
without it.

THE SAFETY NET: if a cabinet is left with nobody (every other cabinet has
gone for 5 seconds), or its game has had no link for 10 seconds, it shows
"LINK LOST - RESTARTING IN 5" and then restarts itself, like switching that
cabinet off and on. If the link comes back during the countdown, nothing
happens. After the restart it looks for the others again: if they are all
starting up too it links with them, otherwise it plays on its own.
(Network page > "If the link is lost": Restart, or Carry on.)


THE GAMES' OWN SETTINGS (their test menus) ARE KEPT
---------------------------------------------------
Each game keeps its own test-menu settings, per cabinet, in a file beside
it (tw_eeprom_cab1.nv, rr_eeprom_cab1.nv, ...), as the boards kept them.

The games have their own cabinet ID in the test menu:
   Tokyo Wars:  GAME OPTIONS > ID NO.
   Rave Racer:  GAME OPTIONS > CPU NUMBER
The first time a cabinet runs, and whenever "This cabinet" is changed on
its Network page, the game's ID is set to that same number when the game
next starts. Otherwise whatever is set in the test menu is kept.
Every linked cabinet needs a DIFFERENT ID, as on the real machines: if two
have the same one, the title bar shows a WARNING naming them.

Other settings work as on the real machines, for example:
   Tokyo Wars:  GAME OPTIONS > TEAM COLOR (green / white side)
   Rave Racer:  GAME OPTIONS > CAR TYPE (car 1-8; blue, yellow, red, green)
                - each cabinet's car shows in its own colour on the others.

(Dirt Dash and Prop Cycle had no link play: this kit is for the two that did.)


IF SOMETHING GOES WRONG
-----------------------
Each cabinet writes a log file beside the program: tokyowar_cab1.log,
raveracer_cab1.log, ... Lines starting with [LINK] say which cabinets it
can hear and whether the game thinks the link is good. Send those files over.


CHECKING THE LINK
-----------------
To switch the link lights on or off for EVERY game at once (Tokyo Wars,
Rave Racer and Time Crisis 2): "0 - START HERE" > 4 Tools > 3. Time
Crisis 2 shows two lights: 1 = the left (red) cabinet, 2 = the right
(blue) one, with grey meaning it is playing alone. Its corner can be set
with lights= in "Time Crisis 2\tc2_link.cfg".
Network page > "Link lights": small lights, one per cabinet, in the corner
of the screen you choose (each corner, or top / bottom centre):
   blue (white edge)  this cabinet - it flickers as it sends
   green              that cabinet and this one hear each other - it
                      flickers as its messages arrive
   amber              one-way: this cabinet hears it, but it cannot hear
                      this one (or its Network page is set up differently)
   red                nothing arrives from that cabinet
   grey               not in this set (it started late, or it is not on)

The waiting screen, the title bar and the log also say it in words, e.g.:
   "Cabinet 3 can't hear this PC"
   "SET-UP DIFFERS: Cabinet 3 is set for 4 cabinets, this PC for 3"
   "SET-UP DIFFERS: Cabinet 2 has a different address list"
   "DIFFERENT VERSION: Cabinet 3's game is dated 29 Sep 22:10, this PC's
    30 Sep 10:15" - copy the same game folder to every PC
Every cabinet must have the same "Cabinets in set", the same address list
(only "This cabinet" is different on each) and the same copy of the game.

NETWORK QUALITY: the waiting screen shows how long a message takes to get
to each cabinet and back ("Cabinet 2: found  4 ms"); the Network page shows
it too ("Link quality"). The games need a message to get round every
cabinet in about a tenth of a second, so a path that is slow or loses
messages is marked POOR ("96 ms, 4% lost - POOR"). On a cable to a switch it
is a few ms. POOR on Wi-Fi: move closer, use a cable, or set the PC's power
plan to "Best performance".

RESTART ALL CABINETS (Network page): press Enter, then Enter again within
5 seconds. Every cabinet of the set restarts at once - like switching the
whole set off and on - and they link up again. Use it when a cabinet was
left out (it started late, or after a crash): no need to go to each PC.
If a cabinet cannot be heard, the first things to check on THAT PC are its
Network page, then its firewall / security software.
