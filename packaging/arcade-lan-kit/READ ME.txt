NAMCO 22 ARCADE LAN
===================

Namco's 1990s arcade games (System 22 and System 23), rebuilt to run on a PC, for real arcade
cabinets: one PC in each cabinet in place of the original boards, the cabinets linked over a wired network the way the
boards were linked by their cable. Nothing here uses the internet.

The games are the work of the namco22-decompile project (spacestate1); this package adds the
cabinet link, the launcher and the cabinet set-up. You need your own copy of the games.

2. THE LAUNCHER
---------------
Double-click "Namco 22 Arcade LAN.exe". The games are on the left, the chosen game's picture and
the ways to play it on the right.
   Arrow keys / D-pad / stick     choose          Enter / A      start
   Esc / B                        back            S / Y          settings
or use the mouse. When a game starts the launcher steps aside; when the game is closed it comes
back. In the games: Esc opens the game's own menu (display, sound, controls, Network);
File > Exit or Alt+F4 closes the game.

The ways to play:
   Linked cabinet - full screen          this PC is one cabinet in a linked set (the normal choice)
   Linked cabinet - window               the same in a window, for setting up and testing
   Test: 2 / 4 linked cabinets on this PC  linked copies in windows, to see the link working
                                         (Ace Driver also has Test: 8)
   Party: 2 or 4 players                 split screen on one PC, a controller for each player
                                         (Gunmen Wars and Time Crisis II: 2 players, keyboard and
                                         mouse + a controller, or 2 controllers)
   Full screen / Window                  the single-cabinet games, and Gunmen Wars (its link is set
                                         up in the game's own Esc menu, Link page)
   Time Crisis II                        Left or Right cabinet, Both sides on one PC (2 monitors,
                                         2 guns), Test: both sides on this PC, or Party


3. LINKING THE CABINETS (once per set)
-------------------------------------
1. Copy this whole folder to every cabinet PC, connect the PCs to one network switch with
   cables, and give each PC a fixed address (in Windows, or reserved in the router).
2. On EVERY PC start the game with "Linked cabinet - full screen".
3. On each PC press Esc, open the Network page and choose "Find cabinets". After a moment it
   lists the PCs running the game ("Found 3: 192.168.1.11 CABINET-1 (this PC), ..."). Choose
   "Use the N found": the address list is filled in, the same on every PC, with "This cabinet"
   on Auto (each PC's number is its place in the list).
   (Time Crisis II finds the other side by itself: just start "Left cabinet" on one PC and
   "Right cabinet" on the other.)
4. Close the game on every PC and start them all again. The cabinets look for each other when
   they start, like the real boards, wait up to a minute for any that are missing, then begin
   together.
5. The first time, Windows Firewall asks whether the game may use the network: tick "Private
   networks" and click Allow. If it does not ask and the cabinets cannot see each other, that
   permission is the first thing to check.

How the link behaves (the same rule as the real boards):
 - A cabinet started after the others are already playing (late, or after a crash) is not let
   in: it plays on its own until the whole set is started again. "Restart all cabinets" on the
   Network page restarts every cabinet at once, so nobody has to walk round the PCs.
 - If a cabinet is left alone, or its game loses the link for 10 seconds, it shows
   "LINK LOST - RESTARTING IN 5" and restarts itself (Network page > If the link is lost).
 - While linked, the Esc menu does not pause the game: a cabinet that stops is dropped.
 - Each game keeps its own cabinet ID in its test menu (Tokyo Wars: GAME OPTIONS > ID NO.;
   Rave Racer: GAME OPTIONS > CPU NUMBER; Cyber Commando: GAME OPTIONS > CPU NO.;
   Armadillo Racing: GAME OPTIONS > PCB ID, red / blue / yellow / green; Cyber Sled: GAME OPTIONS
   > POSITION, left / right). Every linked cabinet
   needs a different one; a cabinet's first linked run sets it from its cabinet
   number, after that the test menu's is kept (and a warning shows if two linked cabinets have the same one).


4. SET UP AND FORGET: STARTING BY ITSELF
---------------------------------------
For a cabinet, the PC should start the game by itself when it is switched on, with no keyboard:
1. In the launcher: Settings > "Start a game when Windows starts" > choose the game and the way
   to play (for a linked cabinet: "Linked cabinet - full screen"; for Time Crisis II: the Left
   or Right cabinet). "Countdown before the game starts" sets the delay (10 s); a key or
   button during the countdown opens the menu instead.
2. "When the game closes": "Restart the game" (the default) starts it again a few seconds after
   it closes for any reason, so the cabinet always comes back to its attract mode.
3. Windows must sign in by itself: set the cabinet PC's account to sign in automatically
   (Windows: run "netplwiz", untick "Users must enter a user name and password", or the
   equivalent on your Windows version), and switch off sleep and screen-saver in the power
   settings. These are Windows' own settings; the launcher does not change them.
To stop it starting by itself: launcher > Settings > "Start a game when Windows starts" > Off.


5. FITTING A PC IN A CABINET
----------------------------
 - VIDEO: the games draw at the PC's screen resolution. An original 15 kHz arcade monitor needs
   a converter from the PC's VGA/HDMI output to the monitor's RGB (a 15 kHz-capable graphics
   setup or a scan converter); or fit an LCD in the cabinet.
 - CONTROLS: the wheels, pedals, levers, guns and buttons go through an encoder board that the
   PC sees as a keyboard, a joystick or a game controller, e.g. an Ultimarc A-PAC (analog:
   wheels, pedals, levers) or I-PAC (buttons). Then set the keys or axes once on each game's
   Esc menu > Controls page, and calibrate in the game's own test menu as on the real machine.
 - SOUND: the PC's audio output to the cabinet's amplifier.
 - THE NETWORK: a cable from each cabinet to one switch. Wi-Fi works for a test, but it can
   pause for a moment, and that is enough to drop the link.
 - FULL SCREEN: always run a cabinet full screen. In a window a modest PC can freeze for a moment
   in busy scenes, which can drop the link with three or more cabinets.


6. SETTINGS (launcher > Settings)
---------------------------------
   Start a game when Windows starts   Off, or a game and way to play
   Countdown before the game starts   5 - 60 seconds
   When the game closes               restart the game (automatic start) / return to this menu
   Launcher display                   full screen / window
   Link status lights (all games)     small lights in a corner showing the link's activity
   Session recordings (all games)     each game keeps the last session's inputs so a problem
                                      can be replayed (a few KB each); Off keeps none
   This PC's network address          for typing the addresses by hand

The link lights: blue = this cabinet (flickers as it sends); green = that cabinet and this one
hear each other; amber = one-way (it is heard but cannot hear this one); red = nothing from that
cabinet; grey = not in this set.


7. GUNMEN WARS
--------------
 - Ways to play: Full screen, Window, Test: 2 linked cabinets on this PC, and Party: 2 players
   (split screen: keyboard and mouse + a controller, or 2 controllers). Linked cabinets: set them up on the game's own Esc menu > Link page
   ("Find cabinets", then "Use found" on every PC); 2 or 3 cabinets, 4 is experimental.
 - Link page > Network: LAN (cables, the default), Wi-Fi, Slow network or Internet. A slower
   choice adds a little delay but rides out a less steady network; linked PCs all use the
   slowest one set on any of them.
 - THE NAMCAM: the photo taken before team select comes from the PC's webcam, or from a picture
   named photo.jpg / photo.png / photo.bmp in the game's folder (Esc menu > Options > NamCam
   photo: Auto, Webcam, Photo file or Off). Linked cabinets see each other's photos.
 - Esc menu > Options: Controls (FPS: the mouse turns / Cursor), Mouse sensitivity, Crosshair
   (FPS) hidden or shown, Boot notice (skip the 25 s notice), Widescreen outside matches (4:3
   with black bars, the default: the attract demo's scenery only exists as far as the original
   4:3 screen shows; matches always fill the widescreen).
 - Esc menu > Display: Widescreen, Widescreen HUD (the scores at the screen edges), Motion
   smoothing (for 120 Hz screens and up), Depth.
 - F9 saves a CAPTURE (a picture and the game's state) in the captures folder: press it when
   something looks wrong and send the files with the report. F12 takes a plain screenshot.


IF SOMETHING GOES WRONG
-----------------------
Each game writes a log in its folder (tokyowar_cab1.log, raveracer.log, ...); the launcher writes
launcher.log beside itself. Lines starting with [LINK] say which cabinets a game can hear and
whether it thinks the link is good. The game's menu, waiting screen and title bar also say it in
words: "Cabinet 3 can't hear this PC", "SET-UP DIFFERS ...", "DIFFERENT VERSION ..." (copy the same
folder to every PC). Send the logs with any report.
